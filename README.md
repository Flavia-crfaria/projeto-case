## Descrição

O projeto consiste no desenvolvimento de um jogo físico gamificado de precisão, no qual o jogador lança uma bolinha em uma área formada por uma malha de lasers e sensores LDR. A interrupção dos feixes permite identificar a posição atingida nos eixos X e Y, determinar a pontuação da jogada e acender o LED correspondente em uma matriz 8x8.
<br><br>
Os dados gerados durante as partidas serão processados por Arduinos e enviados para um sistema digital, permitindo o registro de pontuações, acertos, posições atingidas e histórico das jogadas em um dashboard. O projeto integra robótica, sensores, eletrônica, programação, comunicação entre dispositivos e gamificação.
